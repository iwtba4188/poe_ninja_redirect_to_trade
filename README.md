## Introduction
A Chrome extension that links the [poe.ninja](https://poe.ninja/builds) build page to the official trading site for all equipment (including flasks, jewels, and gems), and including a built-in feature for Chinese, Korean, and Russian localization of modifiers.

**Note:** Please note that the extension does not support the PoE 2 Ninja page yet.

## Features
- Redirected equipment, flasks, jewels, and gems to the official trade market with a single click.
- Applying filters for modifiers (and for gems, filtering by quality and gem level) while searching.
- Equipment, flasks, and jewels modifiers localized in Chinese, Korean, and Russian.

## Getting Started
**PoE Ninja Redirect to Trade** is currently available on the Chrome Web Store. You can also install it manually.

### Installation
1. Download the ZIP file from the [Github page](https://github.com/iwtba4188/poe_ninja_redirect_to_trade) or [Latest Release](https://github.com/iwtba4188/poe_ninja_redirect_to_trade/releases). Extract the file.
![installation_1](./image/installation_1.png)
2. Take Edge for example, select "Load unpacked."
![installation_2](./image/installation_2.png)
3. Select the extracted file and click OK.
4. Go to any character's equipment page. You can now navigate to the trading marketplace with one click.

### Usage

1. Navigate to any character page, hover the mouse over the equipment, and if 'Trade' appears, it indicates that the system is functioning properly. You can click to proceed to the trading marketplace.
![usage_1](./image/usage_1.png)

2. The method for using flasks and jewels is the same. **Note: The jewel button is located below the jewel image (as shown), and it will not display a green button, but you can still click to proceed.**
![usage_2](./image/usage_2.png)

3. Gems are displayed to the left of the gem name.<br>
![usage_3](./image/usage_3.png)

4. To change the display language of modifiers and other settings, click on the extension icon, then click the dropdown for each setting to change it.
![usage_5](./image/usage_5.png)

5. If some word drop-downs do not take effect immediately, please refresh the page (F5 or Ctrl+R).
![usage_4](./image/usage_4.png)
